Summary: This web-based mapping tool incorporates the principles of power physics and is capable of conducting power flow analysis and hosting capacity calculations based on user inputs. It visualises critical information on a map, including voltage at residential houses, transformer utilisation, and various data plots.

Instructions: Step 1: Download the Back_end file and Front_end file. Step 2: Open both Back_end file and Front_end file using Visaul Studio Code. Step 3: Go to "websocket_server.py", open a terminal and put "python websocket_server.py", press enter. Step 4: Go to "index.html", click on "Go Live" button on the bottom right corner. (if you don't have the button, install "Live Server" at extension)
